## 📌 Özet

DS/ML dünyasında işlerin çoğu ilan açılmadan kapanır — ağ üzerinden. Networking pasif bir aktivite değil, aktif bir kariyer yatırımı. Bu not, teknik toplulukta nasıl görünür olunacağını ve ağ kurma stratejilerini açıklar.

---

## 🧠 Detay

### Neden Networking?

```
"Hidden job market" — iş ilanlarının %70-80'i hiç yayımlanmaz
Referans: Başvuruların %4'ü işe alımla sonuçlanır
          Referansla gelen başvuruların %40'ı sonuçlanır

Sonuç: Tanıdık > CV > LinkedIn başvurusu
```

### Online Networking Platformları

#### LinkedIn (En Kritik)

```
Günlük 15 dakika stratejisi:
  - 5 dk: Sektörden birinin gönderisine değerli yorum
  - 5 dk: Bir bağlantı isteği (ortak nokta belirt)
  - 5 dk: Kendi gönderi (haftalık 2-3 olursa ideal)

Bağlantı isteği mesajı şablonu:
"Merhaba [Ad], [ortak bağlantı/çalıştığı şirket/paylaşımı]
 vesilesiyle ulaşıyorum. [Kısa neden]. Bağlantı kurmak isterim."
```

#### Twitter/X — Teknik Topluluk

```
Takip edilmesi gereken hesaplar (DS/ML):
  @karpathy (Andrej Karpathy)
  @ylecun (Yann LeCun)
  @huggingface
  @weights_biases
  @jeremyphoward (fast.ai)

Türkçe DS topluluğu:
  Kaggle Türkiye Discussion board
  Veri Bilimi Discord sunucuları
  LinkedIn Türkiye DS grupları
```

#### GitHub & Açık Kaynak

```
Katkı türleri:
  → Documentation fix (en kolay giriş)
  → Bug report (detaylı = değerli)
  → Small feature PR
  → Tutorial / example notebook
  → Turkish translation

Katkı sonrası:
  → LinkedIn'de paylaş: "XYZ projesine katkıda bulundum"
  → README'ye katkıcı ekleniyor mu? = sosyal kanıt
```

### Offline Networking — Meetup & Konferanslar

**Türkiye'deki DS/ML etkinlikleri:**

```
Düzenli:
  - DataFest Turkey (yıllık)
  - PyData Istanbul
  - Yapay Zeka Zirvesi
  - Google I/O Extended İstanbul
  - AWS re:Invent Türkiye etkinlikleri

Meetup platformu:
  meetup.com → "Data Science Istanbul", "Python Turkey"

Konferans katılımı:
  → Konuşmacılarla tanış → LinkedIn'de "Etkinlikte tanıştım" ile ekle
  → Soru sor → görünürlük sağlar
  → Hazırsa: kısa talk ver → en etkili ağ kurma
```

### İçerik Üretimi — Düşünce Liderliği

```
İçerik türleri (kolay → zor):
  1. Repost + yorum ekle (5 dk)
  2. Öğrendiklerim thread'i (15 dk)
  3. Blog yazısı (Medium, Hashnode, kendi site) (2-3 saat)
  4. YouTube video / tutorial (en yüksek etki)
  5. Konferans konuşması

İlk içerik fikirleri:
  "X kütüphanesini nasıl kullandım"
  "Kaggle'da öğrendiklerim"
  "XYZ hata nasıl çözüldü"
  "Bu vault notumu bugün öğrendim: [konu]"
```

### Networking E-postası / Mesajı

Biri senden tavsiye isterse veya sen bir kıdemli çalışana ulaşmak istersen:

```
Konu: [Ortak bağlantı] ile DS Kariyer Tavsiyesi

Merhaba [Ad],

[Ortak bağlantı / Konferans / LinkedIn] aracılığıyla profilinize ulaştım.
[Şirket/Proje]'deki çalışmanız dikkatimi çekti, özellikle [spesifik detay].

Ben [kısa tanıtım]. Şu an [durumum] ve [hedefim] için
[kısa spesifik soru — 1-2 soru max].

Zamanınıza saygım var — 20-30 dakikalık bir Zoom görüşmesi
veya yazılı cevap mükemmel olurdu.

Teşekkürler,
[Ad]
[LinkedIn] [GitHub]
```
