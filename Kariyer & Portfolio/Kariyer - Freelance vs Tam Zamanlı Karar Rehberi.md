### Ne Zaman Freelance'e Geç?

```
Hazır olma işaretleri:
  ✓ 2-3 tamamlanmış proje (portfolio'da)
  ✓ Referans mektupları veya testimonial
  ✓ 6 aylık gider karşılığı birikim
  ✓ Müşteri bulma kanalın var (önceki iş çevresi)
  ✓ Vergi/fatura süreçlerini anladın

Erken freelance riskleri:
  ✗ Portfolio yok → müşteri bulmak çok zor
  ✗ Network yok → sürekli soğuk başvuru
  ✗ Birikm yok → ilk 3 ay zor geçer
```

### Freelance Platformları ve Stratejiler

#### Upwork (En Büyük Platform)

```
Başlangıç stratejisi:
  1. Profili %100 doldurun — foto, bio, skills, portfolio
  2. İlk 3-5 iş: düşük teklif ver, hızlı teslim et → review topla
  3. Niş seç: "Data Science" değil "E-ticaret churn modelleme"
  4. JSS (Job Success Score) %90+ tut → Top Rated rozeti

Tipik saatlik ücret (Türkiye'den):
  Junior: $15-25/saat
  Mid: $30-60/saat
  Senior/Expert: $75-150/saat
```

#### Toptal (Üst Segment)

```
Seçim süreci zor (%3 kabul) ama öyle değeri var:
  1. İngilizce yetkinlik testi
  2. Teknik değerlendirme (2 turlu)
  3. Live problem solving
  4. Test proje

Kabul edilince:
  → Küresel şirketlerle $80-200+/saat
  → Türkiye'de çalış, dolar kazan
```

#### Fiverr (Küçük Projeler)

```
DS/ML için uygun paketler:
  "Data analizi ve görselleştirme raporu" — $50-200
  "Python data science projesi" — $100-500
  "ML model kurma ve eğitim" — $200-1000
```

### Türkiye'den Uluslararası Freelance — Yasal Süreç

```
Seçenekler:
  1. Şahıs şirketi aç → fatura kes → döviz kazancı
  2. Limited şirket → daha profesyonel görünüm
  3. Sole Trader (yurt dışı entity) → karmaşık

Pratik adımlar:
  → Vergi numarası al
  → Şahıs şirketi aç (muhasebeci yardımıyla)
  → Wise veya Payoneer → döviz hesabı aç
  → Upwork/Toptal → Payoneer ile çek

Dikkat:
  → Yurt dışı geliri beyan zorunlu
  → KDV muafiyeti (ihracat = KDV 0) var
  → Bir muhasebeciye danış — her durum farklı
```

### Hibrit Model — En İyi Başlangıç

```
Aşama 1 (0-6 ay): Tam zamanlı + hafta sonu freelance
  → Risk sıfır, deneyim + gelir birikiyor
  → İzin günleri Upwork profilini kur

Aşama 2 (6-18 ay): 2-3 düzenli freelance müşteri kazan
  → Aylık serbest gelir ≥ maaş olunca...

Aşama 3: Tam zamanlıdan ayrıl
  → Tam freelance → zamanla ürün/SaaS'a geçiş
```

### Saatlik Ücret Hesaplama

```python
# Gerçek freelance maliyeti hesapla
aylik_gider = {
    'kira_ve_yasam': 20_000,
    'sgk_ve_vergi': 5_000,     # kendi ödersin
    'muhasebeci': 2_000,
    'yazilim_araclar': 1_000,
    'egitim': 1_000,
    'ekipman_amortisman': 500,
}
toplam_aylik = sum(aylik_gider.values())  # 29,500 TL

# Aylık çalışma saati (gerçekçi: 120 saat faturalanabilir)
faturalanabilir_saat = 120
bos_kalan_20_yuzde = faturalanabilir_saat * 0.8  # pazarlama, admin

minimum_tl_saat = toplam_aylik / bos_kalan_20_yuzde  # ~307 TL/saat
minimum_dolar_saat = 307 / 38  # ~$8/saat — bu floor, altına inme
# Hedef: 3-4x floor → $25-35/saat junior için makul
```
